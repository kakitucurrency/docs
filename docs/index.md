# Kakitu's documentation has moved to developer.kakitu.org

Kakitu's documentation is now at **[developer.kakitu.org](https://developer.kakitu.org/)**.

If you are not redirected automatically, follow that link.

Everything previously published here described an earlier version of Kakitu built on Nano
(block lattice, RPC, work generation). None of it is accurate any more, so it has been taken
down. KSHS is now an ERC-20 token on Base, backed one-to-one by USDC; reserve backing is
public at [walletapi.kakitu.org/reserves](https://walletapi.kakitu.org/reserves).
