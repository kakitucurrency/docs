## How to Contribute

### Run a Node

Running a node directly supports the network's decentralization and resilience. See [Run a Node](run-a-node.md) for deployment guides.

### Become a Representative

Hold significant KSHS and become a representative to actively participate in consensus. See [Representative Voting](../running-a-node/representative-voting.md).

### Build on Kakitu

Build wallets, payment tools, merchant integrations, or DeFi experiments using the [Integration Guides](../integration-guides/the-basics.md) and available [libraries](../releases/node-releases.md).

### Contribute Code

See [Contribution Guidelines](contributing.md) for how to submit pull requests to any Kakitu repository.

### Documentation

Help improve these docs by submitting pull requests to [github.com/kakitucurrency/kakitu-docs](https://github.com/kakitucurrency/kakitu-docs).

### Community Support

Answer questions from new users in Discord, help onboard developers, or write tutorials and blog posts.
