# Roadmap

This roadmap outlines the planned development direction for Kakitu. Items are subject to change as priorities evolve and community feedback is gathered.

---

## Phase 1 — Foundation (Q1 2026)

- [x] Genesis launch — main network live
- [x] Core node software (`kakitu-node` v1.0.0)
- [x] Key tooling (`kakitu-keytools`, `gokakitu`, `kakitucurrency-js`)
- [x] CLI wallet (`atto`)
- [x] Block explorer (`explorer.kakitu.org`)
- [x] Work server (`kakitu-work-server`)
- [x] MCP server for AI integrations

## Phase 2 — Ecosystem (Q2–Q3 2026)

- [ ] Mobile wallet (iOS + Android)
- [ ] Hardware wallet support (Ledger integration)
- [ ] Browser extension wallet
- [ ] Fiat on-ramp/off-ramp partnerships (Kenyan payment providers)
- [ ] Merchant point-of-sale SDK
- [ ] NFC payment support (tap-to-pay)
- [ ] USSD interface for feature phones (offline sending)

## Phase 3 — Scale (Q3–Q4 2026)

- [ ] Epoch 2 — differentiated work thresholds
- [ ] Improved bootstrapping performance (lazy bootstrap improvements)
- [ ] Pruning mode (reduced storage requirements for light nodes)
- [ ] Light/SPV node mode (mobile-friendly)
- [ ] Multi-sig support
- [ ] Enhanced WebSocket subscriptions

## Phase 4 — Programmability (2027+)

- [ ] Smart contract layer research
- [ ] Cross-chain bridge (to EVM chains)
- [ ] Stablecoin stabilization mechanism research
- [ ] DAO governance for protocol upgrades
- [ ] Developer grant program

---

## Community Input

The roadmap is shaped by community feedback. To propose a feature or raise a protocol change:

1. Open an issue on [GitHub](https://github.com/kakitucurrency/kakitu-node/issues)
2. Discuss in [Discord](https://discord.gg/kakitu)
3. Submit a Kakitu Improvement Proposal (KIP) — format TBD

---

*Kakitu is open source. Contributions are welcome at every phase.*
